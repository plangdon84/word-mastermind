# Achievement badge drafts

The approved badge designs for Dev Plan item 3b (see README "Achievements").
Open `preview.html` to see them all. `gen.mjs` writes the SVGs and the preview
(`node gen.mjs` in this folder). In the app they become inline Preact
components (`src/app/Badge.tsx`), so this folder is a design reference, not
something the app loads. The streak and feat badges were designed in the app,
in the same style, and aren't drafted here.
